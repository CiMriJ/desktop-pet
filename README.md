# 桌面宠物 一二 & 布布

两只住在桌面上的小熊。透明置顶、随手拖动、会说话，还带番茄钟和喝水 / 久坐提醒。

基于 Electron 33，零运行时依赖，Windows 10 / 11 可用。

仓库地址：<https://github.com/CiMriJ/desktop-pet>

## 功能

### 桌面互动

- **两只独立宠物**：一二和布布各自一个透明窗口，可以分别显示 / 隐藏、分别摆位置。
- **拖动**：按住拖动，松手停在原地，不会掉到屏幕底部，也不会自己乱跑；只有拖出屏幕的部分会被拉回工作区。
- **摸摸头**：左键点击 +1 好感度（0.9 秒冷却），会冒出对话气泡和小爱心。
- **右键菜单**：摸摸、喂小零食（+5 好感度）、一起专注、锁定位置、重置位置、隐藏、打开设置、退出。
- **状态动画**：待机、被点、被拖、提醒、睡觉；系统空闲 5 分钟后自动打盹，你回来就醒。
- **锁定位置**：右键或托盘勾选后无法拖动，防止误碰。

### 实用功能

- **番茄钟**：默认专注 25 分钟、休息 5 分钟，可改为 15/20/30/45/60 分钟；可随时结束，专注结束和休息结束都会由宠物提醒。
- **喝水提醒**：默认每 45 分钟，可选 30/45/60/90/120 分钟。
- **久坐提醒**：默认每 60 分钟提醒起来活动。
- **整点报时**：到点由宠物开口报时，不是生硬的系统通知。
- **免打扰时段**：时段默认 22:00–08:00（开关默认关闭），开启后该时段内不弹提醒和报时。
- **桌面时钟**：宠物旁边显示时间，可在设置里关闭。
- **开机自启**：登录 Windows 后自动运行（仅安装版生效）。
- **单实例**：重复启动只会打开设置窗口，不会多开一群宠物。

### 养成

- 摸摸 +1、投喂 +5，好感度只存本地。
- 等级：初次见面（0）→ 有点熟了（10）→ 好朋友（30）→ 形影不离（60）→ 灵魂伴侣（100）。
- 升级时宠物会撒一把爱心，并说一句悄悄话。

### 自定义形象

- 设置窗口里可以给每个动作单独换 PNG / GIF，换完立即生效，随时可恢复默认。
- 待机、走动、被点、被拖、提醒、睡觉六个状态可分别设置；缺哪个就用内置 SVG 形象顶上，不会报错。

## 快速开始

要求：Windows 10 / 11、Node.js 18+（建议 20 LTS）、npm。

```bash
git clone https://github.com/CiMriJ/desktop-pet.git
cd desktop-pet
npm install
npm start
```

运行单元测试：

```bash
npm test
```

共 21 个用例，覆盖番茄钟、提醒判定、好感度、状态机、配置校验等纯逻辑。

## 打包 Windows 安装包

```bash
npm run setup
```

输出在 `installer-out/`，文件名形如 `桌面宠物一二布布-安装程序-1.1.4.exe`。NSIS 安装器特点：

- 非一键安装，有安装向导
- 支持自定义安装目录
- 创建桌面和开始菜单快捷方式
- 安装完成后可直接启动
- 默认按当前用户安装，不需要管理员权限

注意：`package.json` 里 `build.electronDist` 指向的是本机 Electron 运行时绝对路径（`D:\projects\desktop-pet\node_modules\electron\dist`）。换机器打包时请改成自己的路径，或直接删掉该字段让 electron-builder 自动下载。

其他脚本：

| 命令 | 作用 |
| --- | --- |
| `npm run icons` | 重新生成应用图标 |
| `npm run pack` | 只生成 `dist/app.asar`，用于旧安装目录热更新 |

## 使用说明

- **左键**：摸摸宠物；按住移动则是拖动。
- **右键宠物**：打开宠物菜单。
- **双击托盘图标**：打开「形象与设置」。
- **托盘右键**：显示 / 隐藏宠物、番茄钟、各类提醒、免打扰、置顶、锁定、开机自启、重置位置、退出。
- **退出程序**：关闭设置窗口不会退出，请用托盘菜单或宠物右键菜单里的「退出」。
- **找不到宠物**：托盘菜单 →「重置位置」，会放回屏幕右下角；多显示器拔插后也适用。

## 配置与数据

配置保存在：

```
%APPDATA%\桌面宠物一二布布\config.json
```

自定义形象保存在：

```
%APPDATA%\桌面宠物一二布布\pets\yier\<状态>.png|gif
%APPDATA%\桌面宠物一二布布\pets\bubu\<状态>.png|gif
```

建议通过设置界面或托盘菜单修改配置；程序运行期间直接编辑文件可能被内存中的配置覆盖。

常用字段：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `showYier` / `showBubu` | `true` | 是否显示一二 / 布布 |
| `scale` | `1` | 宠物大小，0.7–1.5 |
| `alwaysOnTop` | `true` | 始终置顶 |
| `locked` | `false` | 锁定位置，锁定后不可拖动 |
| `soundEnabled` | `true` | 提示音 |
| `showClock` | `true` | 宠物旁边显示时间 |
| `waterReminderEnabled` | `true` | 喝水提醒开关 |
| `waterReminderMinutes` | `45` | 喝水间隔，5–240 分钟 |
| `restReminderEnabled` | `true` | 久坐提醒开关 |
| `restReminderMinutes` | `60` | 久坐间隔，5–240 分钟 |
| `chimeEnabled` | `true` | 整点报时 |
| `quietHoursEnabled` | `false` | 免打扰时段开关 |
| `quietStart` / `quietEnd` | `22` / `8` | 免打扰起止小时 |
| `pomodoroWorkMinutes` | `25` | 专注时长，5–120 分钟 |
| `pomodoroBreakMinutes` | `5` | 休息时长，1–60 分钟 |
| `autoLaunch` | `false` | 开机自启 |
| `yierPos` / `bubuPos` | `null` | 宠物中心点的屏幕坐标，`null` 表示默认位置 |
| `affection` | `{ yier: 0, bubu: 0 }` | 好感度 |
| `lastWaterAt` / `lastRestAt` / `lastChimeKey` | `0` / `0` / `""` | 提醒计时用的内部状态 |

删除 `config.json` 后重启即可恢复全部默认值（会丢失好感度）。

## 自定义形象

1. 托盘双击，或右键宠物 →「形象与设置…」。
2. 切到「形象」，选择一二或布布。
3. 在对应动作上点「换图」，选一张 PNG 或 GIF。
4. 想还原就点单项的「恢复默认」，或「全部恢复默认形象」。

文件按状态命名，程序靠文件名识别：

| 状态 | 含义 |
| --- | --- |
| `idle` | 待机 |
| `walk` | 走动 |
| `poke` | 被点击 |
| `drag` | 被拖动 |
| `notify` | 提醒 / 说话 |
| `sleep` | 睡觉 |

静态图用透明背景 PNG，动画用 GIF。没有放图的状态会自动回退到内置形象。

如果是从源码运行，也可以直接替换 `assets/pets/yier/`、`assets/pets/bubu/` 下的内置素材，具体说明见 [放图说明.txt](assets/pets/放图说明.txt)。

## 项目结构

```
src/
  main/      Electron 主进程：窗口、托盘、菜单、拖拽、提醒调度、番茄钟、配置与素材
  preload/   preload 脚本：受控的 IPC 桥
  renderer/  宠物界面与设置界面（原生 HTML / CSS / JS）
  logic/     纯逻辑：状态机、番茄钟、提醒、好感度、台词
  shared/    IPC 通道常量
assets/      应用图标与内置宠物形象
test/        node:test 单元测试
scripts/     图标生成、asar 打包
install.ps1 / 一键更新.bat   旧安装目录的热更新脚本
```

## 实现要点

- **一宠一窗**：260×300 透明置顶窗口，`skipTaskbar` + `showInactive()`，不抢焦点、不占任务栏。
- **点击穿透与命中**：渲染层上报宠物实际占用的矩形，主进程按光标位置轮询（有宠物时 30ms，无宠物时 500ms）切换 `setIgnoreMouseEvents`；带 8px 容差和 12px 迟滞，避免边缘闪烁。
- **拖拽**：按下时记录光标与窗口位置的锚点，主进程每 16ms 按光标跟随 `setPosition`，渲染层只负责上报开始 / 结束，不走默认窗口拖拽。
- **点击判定**：`pointerup` 时比较移动距离（阈值 3px），避免拖拽结束误触「摸摸头」。
- **Windows 兼容**：宠物窗口必须 `focusable: true`，否则在 Windows 上收不到鼠标按下事件，表现就是「完全拖不动」。
- **性能**：常驻 CSS 动画用 `steps()` 降帧；不显示宠物时停止光标轮询；番茄钟状态广播去重；时钟只在文字变化时写 DOM。实测常驻占用约 1.3% 单核，隐藏全部宠物后为 0%。

## 旧安装目录热更新

早期版本可能装在 `D:\新建文件夹 (4)\desktop-pet`。仓库里的 `install.ps1` 和 `一键更新.bat` 用于这种便携目录的热更新：

- 关闭正在运行的宠物
- 首次更新自动备份原 `app.asar` 为 `app.asar.bak`
- 复制新的 `app.asar` 并启动
- 回滚：`powershell -ExecutionPolicy Bypass -File .\install.ps1 -Rollback`

脚本里的安装路径和运行时路径是按当时环境写死的，用之前请先改成自己的路径。全新安装请直接使用安装包，不需要这两个脚本。

## 版本记录

- **1.1.4**：性能优化。常驻动画降帧、去掉不必要的鼠标事件转发与后台节流开关，番茄钟广播去重，降低运行时的 CPU 占用。
- **1.1.3**：修复拖拽。根因是窗口 `focusable: false` 导致 Windows 下收不到鼠标按下；同时把点击判定改到 `pointerup`，修复「拖不动」和「点了没反应」。
- **1.1.x**：新增番茄钟、喝水 / 久坐提醒、整点报时、免打扰时段、好感度养成、系统空闲睡觉、设置窗口换图等功能。

## 说明

- 仅支持 Windows：安装包使用 NSIS，空闲检测依赖 Windows 的 `powerMonitor`。
- 所有配置、好感度和自定义图片只保存在本机 `%APPDATA%`，不联网、不上传。
- 内置形象随项目提供；如果你替换成微信表情包或其他来源的图片，请自行确认素材的使用授权。
